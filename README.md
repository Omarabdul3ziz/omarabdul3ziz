# Omar Abdulaziz

Backend and infrastructure engineer in Cairo, mostly Go.

</div>

From 2021 to 2025 I worked on ThreeFold, a decentralised cloud made of independently owned machines:

- **[zos](https://github.com/threefoldtech/zos)**: the OS every node boots. Networking, storage, health checks, performance monitoring.
- **[grid-proxy](https://github.com/threefoldtech/zos_sdk_go/tree/development/grid-proxy)**: the public API for finding and filtering nodes across the grid.
- **[kubecloud](https://github.com/codescalers/kubecloud)**: managed Kubernetes on the grid. Multi-master cluster deploys, rollback on failure, progress streamed to the client.

Now I self-host open-weight models on GPUs and work on agent harness tooling. That work lives in a private forge.

On the side:

- **[tfgrid-mcp](https://github.com/threefoldtech/tfgrid-mcp)**: an MCP server that deploys VMs on the grid, with a plan you approve first.
- **[gocker](https://github.com/Omarabdul3ziz/gocker)**: a container in about 150 lines of Go (namespaces, chroot, cgroups), built for a talk.
- **[busynux](https://github.com/Omarabdul3ziz/busynux)**: a minimal Linux from a kernel and a BusyBox rootfs, booted under QEMU.
